# SPA Comments

A full-stack SPA application for creating and discussing topics.

The project was developed as a test assignment using **Django REST Framework** and **React**.

---

## Features

- User authentication
- Create discussions
- Leave comments
- Nested comments (replies)
- Pagination
- Sorting discussions:
  - by creation date
  - by number of comments
- Responsive SPA interface
- REST API
- Docker support

---

## Tech Stack

### Backend

- Python 3.13
- Django
- Django REST Framework
- PostgreSQL
- JWT Authentication
- Docker

### Frontend

- React
- TypeScript
- Vite
- Axios

---

## Running locally (choose the `dev` branch)

### Clone the repository

```bash
git clone https://github.com/GilevIlya/SPA-Comments..git
cd SPA-Comments.
```

### Run with Docker

```bash
docker compose up --build
```
